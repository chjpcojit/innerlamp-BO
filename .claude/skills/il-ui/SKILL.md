# Svelte UI

Stack: Svelte 5 (runes forced on in `vite.config.ts`), Tailwind CSS 4, shadcn-svelte (style `nova`), bits-ui, `tailwind-variants`.

## Where things go
- `src/lib/components/ui/*` — shadcn primitives. **Generated by the CLI. Do not hand-edit.** Add with `npx shadcn-svelte@latest add <name>`, then check the diff.
- `src/lib/components/*.svelte` — app components, kebab-case file names (`data-table-status.svelte`). Group a family with a shared prefix.
- `src/lib/hooks/*.svelte.ts` — reusable reactive helpers (see `il-state`).
- `src/routes/<segment>/+page.svelte` — pages. Shared shell in `+layout.svelte`. Global CSS only in `src/routes/layout.css`.
- Aliases: `$lib`, `$lib/components`, `$lib/components/ui`, `$lib/hooks`, `$lib/utils`.

## Component rules
- Runes only: `let { a, b = 1 }: Props = $props()`, `$state`, `$derived`, `$effect`. No `export let`, no `$:`, no stores for new code.
- Events are props (`onclick`, `onCheckedChange`), not `on:` directives. Children via `{@render children?.()}`; snippets instead of slots.
- Import primitives with the existing style: `import * as Card from "$lib/components/ui/card/index.js"` and `import { Button } from "$lib/components/ui/button/index.js"`.
- Merge classes with `cn()` from `$lib/utils`; variants with `tailwind-variants`. Use theme tokens (`bg-card`, `text-muted-foreground`), never hard-coded hex colours; keep dark-mode variants.
- Icons: existing code imports `@tabler/icons-svelte/icons/<name>` per icon (`components.json` says remixicon, but the dashboard block uses tabler). Match the file you are editing; do not mix libraries in one component.
- Keep components presentational. Logic beyond a few lines of `$derived` goes to a viewmodel (`il-state`), so it can be unit-tested.
- Accessibility: semantic elements, `aria-label` on icon-only buttons, visible focus (primitives already provide it), keyboard-reachable interactions.

## Formatting
`npm run format` (tabs, single quotes, no trailing commas, width 100, Tailwind class sorting). Files under `ui/` and older generated files use double quotes; do not reformat them wholesale.

## Verify
Run `il-quality`. For visual changes also open the page (`npm run dev`, e.g. `/dashboard-01`) and check light + dark and a narrow viewport. Add tests per `il-testing`.
